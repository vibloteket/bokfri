# Report templates

The canonical report source tree is `src/main/resources/reports/report/`.
All templates are compiled during `mvn verify` so invalid sources fail the build. At runtime,
templates are loaded from packaged classpath resources, compiled on first use, and reused from
an in-memory cache for the rest of the process. Bokfri does not write compiled report files to
the installation or user data directories. The final `JasperDesign` assembled from these static
template parts is dynamic and is compiled for each generated report.
